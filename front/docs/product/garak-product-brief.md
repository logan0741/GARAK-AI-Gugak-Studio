# GARAK 제품 기준

상태: 현재 기준
작성일: 2026-06-11
문서 책임: GARAK의 제품 정체성, MVP 범위, 핵심 사용자 흐름을 짧게 고정한다.

관련 문서: `../document-authority-index.md`, `screen-flow/current-screen-flow.md`, `../domain/README.md`

## 제품 정체성

- 정식 서비스명은 `GARAK`이다.
- 부제는 `AI GUGAK STUDIO`이다.
- GARAK은 가야금 전용 앱이 아니라 모바일 국악 창작 앱이다.
- MVP에서 사용자가 직접 다루는 악기는 가야금, 장구, 대금이다.
- 악기 선택 화면의 잠금 악기는 MVP 3악기의 미완성 표시가 아니라, 이후 악기를 추가할 수 있음을 보여주는 확장 슬롯이다.

## MVP 목표

사용자가 로그인 없이 앱을 열고, 악기를 고르고, 직접 연주하고, 녹음한 연주를 저장하거나 트랙/레이어 편집에서 확장할 수 있어야 한다.

MVP의 품질 기준은 기능 수보다 첫 연주 경험, 세션 저장, 장단 추천, 따라하기 흐름의 설득력이다.

## 핵심 흐름

1. 앱 실행 후 게스트 상태로 홈에 진입한다.
2. 홈에서 자유창작 모드와 따라하기 모드 중 현재 연주 흐름을 고른다.
3. 자유창작에서는 가야금, 장구, 대금 중 연주할 악기를 고른 뒤 연주로 진입한다.
4. 자유창작에서는 녹음, 저장, 레이어 편집, 장단 추천으로 이어진다.
5. 따라하기에서는 민요를 고르고 악기를 선택한 뒤, 가이드에 맞춰 연주하고 결과 피드백을 받는다.
6. 로그인은 선행 조건이 아니다. 보관함 동기화나 계정에 저장된 곡 불러오기가 필요할 때 설정에서 제안한다.

## 내비게이션 원칙

- MVP에서는 모든 화면에 붙는 전역 하단 탭을 두지 않는다.
- 홈은 자유창작 모드와 따라하기 모드를 고르는 첫 진입점이다.
- Figma의 `마이 / 홈 / 쉐어`는 전역 라우팅 바가 아니라 홈 주변 빠른 접근 UI로 해석한다.
- 연주 화면은 몰입을 우선하며, 하단 UI는 전역 이동보다 연주 중 컨트롤을 담당한다.

## 데이터 원칙

- 사용자에게 보이는 저장 단위는 세션과 테이크다.
- 내부적으로는 악기 입력 이벤트, 세션 메타데이터, 트랙 구성을 함께 보존한다.
- 녹음 파일은 공유나 재생을 위한 선택 산출물이다.
- 게스트도 로컬 보관함에 저장할 수 있다.
- 로그인 후에는 계정 보관함과 로컬 보관함을 병합하거나 선택 동기화한다.
- 정상 연주 중 앱은 공공 음원 사이트를 직접 호출하지 않는다.

## 음원 / 샘플 원칙

- 국립국악원 디지털음원 자료는 주요 원천 후보로 둔다.
- 백엔드는 필요한 음원을 내려받아 권리, 출처, 품질을 확인한 뒤 서버에 저장한다.
- 앱은 서버가 제공하는 `SampleAssetManifest`를 통해 필요한 샘플을 캐시하거나 일부 필수 샘플을 번들로 포함한다.
- 화면은 샘플 준비 상태를 숨기지 않는다.

## AI 원칙

- MVP의 AI 반주는 생성형 오디오가 아니다.
- 사용자의 연주 이벤트를 분석해 장단을 추천하고, 사용자가 미리듣고 수락하면 로컬 시퀀싱으로 반주 트랙을 추가한다.
- 결과 화면의 AI 피드백은 데모 레이어로 둘 수 있으며, 외부 API가 실패해도 로컬 템플릿 피드백으로 대체 가능해야 한다.
