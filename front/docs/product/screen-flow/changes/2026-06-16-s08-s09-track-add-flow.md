# 2026-06-16 S08/S09 트랙 추가 흐름 결정

상태: 채택

관련 문서: `../current-screen-flow.md`

## 결정

- S08은 악기 목록 화면이 아니라 트랙 타입 선택 화면으로 둔다.
- S08의 첫 선택지는 `악기 연주 추가`, `장단/반주 추가`, `가져오기`다.
- `가져오기`는 MVP에서는 잠금 또는 추후 지원 상태로 표시한다.
- `악기 연주 추가`를 선택한 뒤 가야금, 장구, 대금 중 추가 녹음할 악기를 고른다.
- `장단/반주 추가`를 선택하면 S10 `장단 및 반주 패널`로 이동한다.
- S09는 기존 작업의 트랙을 들으며 선택한 악기를 새 레이어로 녹음하는 화면이다.
- S09에서 `적용`하면 녹음한 테이크가 S07의 새 트랙으로 추가된다.

## 이유

- 트랙 추가에는 악기뿐 아니라 장단/반주, 추후 가져오기 같은 여러 타입이 들어간다.
- S08에서 악기 목록을 바로 보여주면 트랙 타입과 악기 선택 책임이 섞인다.
- 트랙 타입을 먼저 고르면 S07의 하단 UI를 단순하게 유지하면서도 이후 기능 확장이 쉽다.
- S09를 S05와 분리하면 첫 연주와 덧녹음의 목적 차이가 명확해진다.

## 후속

- 악기 연주 추가 후 S04A 수준의 악기별 기본 설정을 다시 보여줄지 정한다.
- 추가 녹음 트랙의 시작 위치 기준을 정한다.
- S09에서 기존 트랙의 mute/solo 상태를 어떻게 가져올지 정한다.
