# 2026-06-16 S07 박자 단위 트랙 편집 결정

상태: 채택

관련 문서: `../current-screen-flow.md`

## 결정

- S07 MVP에서는 트랙 위치 이동을 박자 단위로 허용한다.
- 사용자는 트랙을 박자 그리드 위에서 옮길 수 있지만, 기본 UI에서는 밀리초 단위 자유 이동을 제공하지 않는다.
- 세밀한 위치 조정은 숙련자용/전문가용 확장 기능으로 열어둔다.
- MVP 편집 범위는 재생/정지, 트랙 목록, 볼륨, mute/solo, 삭제, 트랙 추가, 장단 추가, 작업 저장, 음원 내보내기, 박자 단위 위치 이동으로 제한한다.
- 파형 자르기, 피치 보정, 자동 박자 보정, 복잡한 믹싱, DAW 수준 타임라인 편집은 MVP에서 제외한다.

## 이유

- 박자 단위 이동은 레이어 편집 감각을 제공하면서도 초보자가 이해하기 쉽다.
- 자유 이동을 기본으로 제공하면 S07이 과도하게 복잡해지고, 모바일에서 정확한 조작이 어려워진다.
- 세밀한 보정 필요성은 인정하되, 기본 흐름을 방해하지 않도록 고급 기능 후보로 분리한다.

## 후속

- 세밀한 위치 조정을 열 경우 진입 방식, 표시 단위, undo/redo 필요성을 별도로 정의한다.
