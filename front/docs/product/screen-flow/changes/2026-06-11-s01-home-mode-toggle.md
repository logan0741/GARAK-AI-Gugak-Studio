# S01 홈 변경 기록: Figma 모드 토글 우선

작성일: 2026-06-11
대상 화면: S01 홈
상태: 반영됨

## 기존 화면

- 상단에 `GARAK` 로고와 언어 전환 아이콘이 있다.
- 중앙에는 큰 단일 카드가 있다.
- 카드 문구는 `GARAK과 함께 국악 연주하기`이다.
- 카드 우측 하단의 화살표가 다음 행동을 담당한다.
- 하단에는 `마이 / 홈 / 쉐어` 빠른 접근 UI가 있다.
- 로그인 관문은 없다.
- 모든 화면에 붙는 전역 하단 탭도 없다.

## 중간 검토안

- 한 차례 `악기 선택 우선` 홈을 검토했다.
- 이 안에서는 홈 중앙의 큰 카드가 선택된 악기를 중심으로 보여주고, `연주 시작`이 자유연주로 바로 진입하는 구조였다.
- 이 검토안은 Figma 원형보다 악기 선택을 먼저 드러내지만, 디자이너가 만든 상단 모드 토글 의도를 약하게 만든다.

## 변경 화면

- Figma C안처럼 홈의 중심 질문은 `연주 모드를 선택해요.`로 둔다.
- 상단 또는 카드 상단에 `자유창작 모드 / 따라하기 모드` segmented toggle을 둔다.
- 중앙의 큰 카드는 선택된 모드 설명을 보여준다.
- `자유창작 모드`에서 `Next`를 누르면 S04 `악기 선택`으로 이동한다.
- S04에서 악기를 고르고 `Next`를 누르면 S04A `연주 기본 설정`으로 이동한다.
- S04A에서는 초보자가 default 설정값으로 바로 시작할 수 있도록 `기본값으로 시작`을 1차 CTA로 둔다.
- `따라하기 모드`에서 `Next`를 누르면 S13 `민요 선택`으로 이동한다.
- 가야금, 장구, 대금은 홈의 첫 선택지가 아니라 자유창작/따라하기 흐름 안에서 선택한다.
- `마이 / 홈 / 쉐어`는 유지하되 전역 하단바가 아니라 홈 화면의 빠른 접근 UI로 둔다.
- 홈에서 입문 가이드, 보관함, 설정으로도 진입할 수 있어야 한다.

## 변경 이유

- GARAK은 가야금 위주 앱이 아니라 국악 창작 앱이다.
- MVP에서 가야금, 장구, 대금을 모두 구현 목표로 삼는다.
- 다만 홈에서 첫 질문을 악기로 바꾸면 Figma의 `자유창작 / 따라하기` 토글 의도가 약해진다.
- 따라하기는 보조 기능이 아니라 자유창작과 동등한 연주 모드로 보여야 한다.
- 따라서 디자이너가 잡은 Figma 원형을 존중해 홈에서는 모드 선택을 우선한다.

## 후속 영향

- `S01 홈`은 모드 선택 화면으로 정의한다.
- `S04 악기 선택`, `S04A 연주 기본 설정`, `S05 악기 자유연주`, `S08 트랙 추가`, `S09 추가 악기 녹음`, `S14 따라하기 악기 선택`을 모두 3악기 기준으로 다시 본다.
- 샘플 데이터 흐름에 악기별 준비 상태와 다운로드/캐시 상태가 추가된다.
- 화면 문구에서 "가야금 시작"이나 "악기 먼저 선택"을 홈 기본 CTA로 고정하지 않는다.
- 이 결정은 영구 확정이 아니며, 2026-06-15에 "Figma C안처럼 홈의 1차 선택을 자유창작 모드 / 따라하기 모드 토글로 두는 결정이 여전히 유효한가요?"를 다시 묻는다.
