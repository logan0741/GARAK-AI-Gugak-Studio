# 2026-06-18 S12-S23 화면 구성 완료 결정

상태: 채택

관련 문서: `../current-screen-flow.md`

## 결정

- S12 `따라하기 모드 상태`는 독립 화면으로 만들지 않고 S01 홈의 모드 선택 상태로 흡수한다.
- S13-S16은 따라하기 흐름으로 묶는다: 민요 선택, 따라하기 악기 선택, 따라하기 연주, 결과/AI 피드백.
- 따라하기 결과는 자유창작 작업으로 자동 변환하지 않고 `PracticeAttempt`와 결과 데이터로 저장한다.
- S17은 공유 준비 화면이며, 공유 대상은 내보낸 음원 또는 따라하기 결과다. 자동 저장된 작업은 직접 공유하지 않는다.
- S18 보관함은 `작업`과 `내보낸 음원/결과`를 구분한다.
- S19는 내보낸 음원 또는 따라하기 결과를 듣고 공유하거나 원본 작업으로 돌아가는 상세/플레이어 화면이다.
- S20/S21은 공유 피드와 공유 곡 상세이며, 실제 커뮤니티 백엔드가 없으면 MVP에서 데모 피드로 대체할 수 있다.
- S22/S23은 설정과 로그인/동기화 흐름이다. 로그인은 앱 시작 조건이 아니라, 계정에 저장된 곡을 불러오거나 동기화할 때만 제안한다.

## 이유

- S01의 모드 토글 결정과 중복되는 S12 독립 화면을 제거해 첫 흐름을 짧게 유지한다.
- 자유창작의 `작업`과 따라하기의 `결과`를 분리해 보관함과 공유 기준을 명확히 한다.
- 공유는 완성된 산출물 기준으로 제한해, 편집 중인 작업이 공유 가능한 곡처럼 보이는 혼란을 막는다.
- 로그인은 자연스럽게 필요한 순간에 제안해야 하므로 설정/동기화 흐름에 둔다.

## 후속 확장

- S20/S21의 실제 커뮤니티 피드는 백엔드 준비 상태에 맞춰 데모 피드에서 실서비스 피드로 교체한다.
- 따라하기 결과의 AI 피드백은 외부 API 없이 로컬 템플릿으로 시작하고, 안정화 이후 외부 API를 붙일 수 있다.
