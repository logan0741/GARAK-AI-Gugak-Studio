# 2026-06-16 S10A/S10B 장단 책임 분리 결정

상태: 채택

관련 문서: `../current-screen-flow.md`

## 결정

- 기존 S10 `장단 및 반주 패널`은 두 화면 책임으로 나눈다.
- S10A `라이브 장단 가이드`는 S05에서 연주 중 들을 장단 가이드를 설정한다.
- S10B `반주 트랙 만들기`는 S08의 `장단/반주 추가`에서 진입해 S07 작업에 새 반주 트랙을 생성한다.
- S10A와 S10B는 장단 프리셋, BPM, 볼륨, 미리듣기 UI 컴포넌트를 공유할 수 있다.
- 화면 책임은 공유하지 않는다. S10A는 라이브 가이드 적용, S10B는 반주 트랙 생성을 담당한다.
- S11 `반주 적용 후 트랙/레이어 편집`은 독립 화면으로 만들지 않는다. S10B 적용 후 S07에 반주 트랙이 추가된 상태로 복귀한다.

## 이유

- 라이브 장단 가이드와 반주 트랙 제작은 진입 맥락, 저장 결과, 사용자 의도가 다르다.
- 하나의 S10으로 묶으면 단일 책임 원칙이 흐려지고, `적용`의 의미가 상황마다 달라진다.
- 화면은 분리하고 컴포넌트만 공유하면 UI 일관성과 책임 분리를 동시에 유지할 수 있다.

## 후속

- S10A/S10B의 MVP 장단 프리셋 목록과 기본 BPM을 정한다.
- S10B의 반주 트랙 시작 위치 기준을 정한다.
- AI 추천 장단을 S10B에서 언제, 어떤 우선순위로 보여줄지 정한다.
