# S01 홈 변경 기록: 3악기 허브

작성일: 2026-06-11
대상 화면: S01 홈
상태: 반영됨

## 기존 화면

- 상단에 `GARAK` 로고와 언어 전환 아이콘이 있다.
- 중앙에는 큰 단일 카드가 있다.
- 카드 문구는 `GARAK과 함께 국악 연주하기`이다.
- 카드 우측 하단의 화살표가 다음 행동을 담당한다.
- 하단에는 `마이 / 홈 / 쉐어` 빠른 접근 UI가 있다.
- 로그인 관문은 없다.
- 모든 화면에 붙는 전역 하단 탭도 없다.

## 변경 화면

- 기존 형태는 유지하되, 단일 소개 카드가 아니라 세 악기 선택 허브로 바꾼다.
- 홈의 중심 질문은 "오늘은 어떤 악기로 가락을 만들까요?"에 가깝다.
- 카드 또는 캐러셀 안에서 가야금, 장구, 대금을 선택할 수 있어야 한다.
- 선택된 악기의 짧은 설명, 샘플 준비 상태, 연주 시작 CTA를 보여준다.
- `가야금 바로 연주`가 아니라 `악기 선택 -> 연주 시작` 구조를 기본으로 한다.
- 선택된 악기에서 `연주 시작`을 누르면 S04 설정 화면을 먼저 거치지 않고 S05 자유연주 화면으로 바로 진입한다.
- 선택 악기의 필수 샘플이 준비되지 않은 경우에는 홈에서 준비 상태와 필요한 조치를 먼저 보여준다.
- `마이 / 홈 / 쉐어`는 유지하되 전역 하단바가 아니라 홈 화면의 빠른 접근 UI로 둔다.
- 홈에서 입문 가이드, 따라하기, 악기 및 조율, 보관함으로도 진입할 수 있어야 한다.

## 변경 이유

- GARAK은 가야금 위주 앱이 아니라 국악 창작 앱이다.
- MVP에서 가야금, 장구, 대금을 모두 구현 목표로 삼는다.
- 홈은 첫 악기를 강제하는 화면이 아니라 세 악기 중 창작 출발점을 고르는 화면이어야 한다.
- 기존 Figma의 미니멀한 홈 구조는 유지하되, 정보 구조를 3악기 허브로 확장한다.

## 후속 영향

- `S01 홈`, `S04 악기 및 조율 설정`, `S05 악기 자유연주`, `S08 트랙 추가`, `S09 추가 악기 녹음`, `S14 따라하기 악기 선택`을 모두 3악기 기준으로 다시 본다.
- 샘플 데이터 흐름에 악기별 준비 상태와 다운로드/캐시 상태가 추가된다.
- 화면 문구에서 "가야금 시작"을 기본 CTA로 고정하지 않는다.
- 이 결정은 영구 확정이 아니며, 2026-06-15에 "여전히 이 결정이 유효한가요?"를 다시 묻는다.
