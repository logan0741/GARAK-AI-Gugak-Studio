# 따라하기, 공유, 보관함, 설정 화면군 구현 계획

상태: 구현 전 실행 기준
작성일: 2026-06-18
문서 책임: S13-S23 화면군 구현 기준이다.

관련 문서: `README.md`, `../../../product/screen-flow/current-screen-flow.md`, `../../../product/screen-flow/screen-composition-standards.md`

## 범위

이 문서는 따라하기 모드, 결과/피드백, 공유 준비, 보관함, 쉐어 둘러보기, 설정과 로그인/동기화를 다룬다.

## 구현 파일

- `src/product/practiceScreens.tsx`
- `src/product/libraryScreens.tsx`
- `src/product/shareScreens.tsx`
- `src/product/settingsScreens.tsx`
- `src/product/productFixtures.ts`

## S13 민요 선택

주요 구현:

- 아리랑, 도라지, 뱃노래 목록
- 난이도
- 예상 길이
- 지원 악기
- 가이드 준비 상태
- 미리듣기

선택 후 S14로 이동한다.

## S14 따라하기 악기 선택

주요 구현:

- 가야금, 장구, 대금
- 추천 악기 배지
- 악기별 따라하기 난이도
- `Next`

추천 악기는 선택을 강제하지 않는다.

## S15 따라하기 연주

주요 구현:

- 선택 민요와 악기 표시
- 악기별 연주 영역
- 다음 입력 가이드
- 실시간 타이밍 피드백
- `시작`
- `완주`
- `중단`

결과 보기를 선택하면 S16으로 이동한다. 따라하기 입력은 `PracticeAttempt`로 기록하고 자유창작 작업 트랙으로 자동 추가하지 않는다.

## S16 결과 / AI 피드백

주요 구현:

- 전체 정확도
- 타이밍 정확도
- 잘 된 부분
- 다시 연습할 부분
- 로컬 템플릿 피드백
- `다시 연주`
- `저장`
- `공유`

외부 API가 없어도 화면은 로컬 피드백으로 동작한다.

## S17 공유 준비

주요 구현:

- 공유 대상 제목
- 길이
- 사용 악기
- 미리듣기
- `공유하기`
- `저장만 하기`

공유 대상은 내보낸 음원 또는 따라하기 결과다. 자동 저장된 작업은 직접 공유하지 않는다.

## S18 보관함

주요 구현:

- `작업`
- `내보낸 음원/결과`
- 최근 작업
- 검색
- 저장 위치: 로컬 또는 계정 동기화 상태
- 빈 상태 CTA

작업 열기는 S07, 결과 상세는 S19로 이동한다.

## S19 연주 상세 / 플레이어

주요 구현:

- 제목
- 재생/일시정지
- 진행 바
- 길이
- 사용 악기
- 원본 작업 연결 여부
- `편집으로 열기`
- `공유`

원본 작업이 없는 경우 `편집으로 열기`는 비활성화한다.

## S20 쉐어 / 둘러보기

주요 구현:

- 데모 피드
- 제목
- 작성자 표시명
- 사용 악기
- 재생
- 리믹스
- 저장

실제 커뮤니티 백엔드가 없어도 데모 피드로 화면 흐름을 확인한다.

## S21 공유 곡 상세

주요 구현:

- 공유 곡 플레이어
- 작성자 표시명
- 설명
- 출처
- 리믹스 가능 여부
- `리믹스`
- `저장`

리믹스는 새 작업을 만들고 S07로 이동한다.

## S22 마이 / 설정

주요 구현:

- 게스트 또는 로그인 상태
- 로컬 보관함 요약
- 언어 설정
- `로그인하고 내 곡 불러오기`
- 도움말

로그인 CTA는 저장/복구/다른 기기 이어하기 이유와 함께 보여준다.

## S23 로그인 / 보관함 동기화

주요 구현:

- 로그인 제공자 placeholder
- 로컬 보관함 요약
- 계정 보관함 요약
- 충돌 항목 수
- `로그인`
- `동기화`
- `선택해서 가져오기`
- `건너뛰기`

로그인 취소나 동기화 실패는 로컬 데이터 유지로 처리한다.

## 테스트 기준

- S13에서 곡 선택 후 S14로 이동한다.
- S14에서 추천 악기가 아니어도 선택 가능하다.
- S16 저장은 보관함 결과 목록에 항목을 만든다.
- S17은 작업만 받은 경우 공유 불가 상태를 표시한다.
- S18은 작업과 내보낸 음원/결과를 분리한다.
- S23 동기화 미리보기는 로컬 항목을 보존한다.
