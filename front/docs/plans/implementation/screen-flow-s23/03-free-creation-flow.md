# 자유창작 화면군 구현 계획

상태: 구현 전 실행 기준
작성일: 2026-06-18
문서 책임: S01, S04, S04A, S05, S07, S08, S09, S10A, S10B 구현 기준이다.

관련 문서: `README.md`, `../../../product/screen-flow/current-screen-flow.md`, `../../../product/screen-flow/screen-composition-standards.md`

## 범위

자유창작 흐름은 사용자가 악기를 선택하고, 연주하고, 자동 저장된 작업을 트랙/레이어 편집 화면에서 관리하는 흐름이다.

## 구현 파일

- `src/product/freeCreationScreens.tsx`
- `src/product/instrumentSurfaces.tsx`
- `src/product/jangdanControls.tsx`
- `src/product/productFixtures.ts`

## S01 홈

주요 구현:

- GARAK 로고와 부제
- `자유창작 모드 / 따라하기 모드` 토글
- 선택 모드 설명 카드
- `Next`
- 홈 빠른 접근: 마이, 홈, 쉐어

S01에서 악기 선택 카드는 노출하지 않는다. 자유창작 모드의 `Next`가 S04로 이동한다.

## S04 악기 선택

주요 구현:

- 가야금, 장구, 대금 선택
- 미래 악기 잠금 슬롯
- 잠금 슬롯은 잠금 아이콘만 표시
- `Next`는 선택 가능한 악기에만 활성화

## S04A 연주 기본 설정

주요 구현:

- 선택한 악기별 설정 항목
- `기본값으로 시작`
- `직접 조정`
- `Next`

악기별 설정:

- 가야금: 조율, 터치 민감도, 잔향
- 장구: 타격 민감도, 장단 가이드 볼륨
- 대금: 운지 민감도, 호흡 표현 강도

## S05 악기 자유연주

주요 구현:

- 선택 악기 중심 연주 영역
- 녹음 상태
- `장단`
- `완료`
- `레이어 편집`

완료 동작:

1. 현재 테이크를 작업으로 자동 저장한다.
2. 처리 중 상태를 S05 안에서 보여준다.
3. S07로 이동한다.

녹음 이벤트가 없어도 짧은 테이크는 저장 가능하다. 저장 불가능한 조건은 데이터 손상이나 필수 식별자 누락으로 제한한다.

## S07 트랙/레이어 편집

주요 구현:

- 현재 작업 제목
- 트랙 목록
- 박자 그리드
- 재생 헤드
- 트랙별 볼륨, mute, solo, 삭제
- `트랙 추가`
- `작업 저장`
- `내보내기`

MVP 편집 범위:

- 박자 단위 이동
- 트랙 순서와 볼륨 조정
- 세밀한 밀리초 단위 편집은 숙련자용 확장으로 남긴다.

## S08 트랙 추가

주요 구현:

- `악기 연주 추가`
- `장단/반주 추가`
- `가져오기` 잠금
- 취소

`악기 연주 추가`는 S09로, `장단/반주 추가`는 S10B로 이동한다.

## S09 추가 악기 녹음

주요 구현:

- 기존 작업 미니 타임라인
- 선택 악기 연주 영역
- 기존 트랙 재생 상태
- `녹음`
- `적용`
- `다시 녹음`
- `취소`

적용 시 새 악기 트랙이 S07에 추가된다.

## S10A 라이브 장단 가이드

주요 구현:

- 장단 프리셋: 세마치, 중모리, 자진모리
- GARAK 기본 BPM
- BPM 조정
- 볼륨 조정
- `미리듣기`
- `적용하고 연주로 돌아가기`
- `끄기`

S10A는 트랙을 만들지 않고 S05의 테이크 메타데이터에 `liveJangdanGuide`를 남긴다.

## S10B 반주 트랙 만들기

주요 구현:

- S10A와 같은 장단 프리셋과 BPM 범위
- 현재 작업 맥락
- `미리듣기`
- `반주 트랙 추가`
- `취소`

S10B는 새 반주 트랙을 생성하고 S07로 돌아간다.

## 테스트 기준

- S05 완료가 `autoSaveTakeAsWork`를 호출하는 흐름으로 표현된다.
- S08의 `가져오기`는 잠금 상태다.
- S10A 적용은 트랙 수를 늘리지 않는다.
- S10B 적용은 반주 트랙 수를 늘린다.
- S07 내보내기는 공유 가능한 산출물을 만든다.
