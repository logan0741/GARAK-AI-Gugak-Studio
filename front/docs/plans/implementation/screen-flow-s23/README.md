## 목표

S01-S23 화면 구성을 실제 앱에서 이동 가능한 화면 구조로 구현한다. 이번 구현의 중심은 화면 흐름, CTA, 상태 전환, 작업/보관함 데이터 구조다. 실기기 오디오 검증은 이번 범위에서 제외한다.

## 구현 원칙

- `current-screen-flow.md`의 화면 목적, CTA, 연결을 우선한다.
- 제품명은 `GARAK`, 부제는 `AI GUGAK STUDIO`로 표시한다.
- MVP 악기 범위는 가야금, 장구, 대금이다.
- 로그인은 시작 관문이 아니다. S22/S23에서 필요한 이유가 있을 때만 제안한다.
- 자동 저장된 작업은 공유 가능한 음원이 아니다. 공유 대상은 내보낸 음원 또는 따라하기 결과다.
- S06, S11, S12는 독립 화면으로 만들지 않는다.
- 기존 가야금 프로토타입은 기술 검증 자산으로 보존하고, 제품 화면 흐름에서는 필요한 영역만 연결한다.

## 구현 산출물

- 화면 흐름 데이터와 상태 전이 테스트
- 작업/보관함 도메인 모델과 순수 함수 테스트
- Expo 앱 첫 화면을 GARAK 화면 흐름 앱으로 교체
- S01-S23 중 제외 화면을 제외한 화면 구조 구현
- 실기기 검증 제외 범위의 `npm test`, `npm run typecheck` 통과
- 팀 보고용 Markdown 문서

## 실행 순서

1. 화면 정의와 라우팅 상태를 먼저 만든다.
2. 작업/보관함 데이터 모델을 테스트 주도로 만든다.
3. 자유창작 흐름을 연결한다.
4. 따라하기, 공유, 보관함, 설정 흐름을 연결한다.
5. 전체 화면 흐름 수동 점검과 자동 검증을 수행한다.
6. 보고용 문서를 작성한다.
