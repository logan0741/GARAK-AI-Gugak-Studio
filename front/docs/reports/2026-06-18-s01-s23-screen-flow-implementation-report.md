## 요약

S01-S23 화면 구성 논의 결과를 Expo 앱의 실제 화면 흐름 셸로 구현했다. 이번 구현은 실기기 오디오 검증, 실제 로그인, 실제 공유 API, 실제 음원 인코딩을 제외하고, 사용자가 각 화면을 이동하며 제품 구조를 확인할 수 있는 수준을 목표로 했다.

앱 진입점은 기존 가야금 기술 프로토타입에서 `GARAK` 화면 흐름 앱으로 교체했다. 기존 프로토타입 코드는 삭제하지 않고 `src/prototype/`에 보존했다.

팀 리뷰용 시각 자료는 `2026-06-18-s01-s23-screen-flow-visual-map.md`에 분리했다.

## 구현된 화면 구조

### 홈과 자유창작

- S01 홈: `자유창작 모드 / 따라하기 모드` 토글, 큰 설명 카드, `Next`, 홈 전용 `마이 / 홈 / 쉐어`, 입문 가이드 진입
- S03 입문 가이드: 기본 제스처 안내 후 S05 진입 가능
- S04 악기 선택: 가야금, 장구, 대금 선택과 추후 악기 잠금 슬롯
- S04A 연주 기본 설정: 악기별 설정 항목과 `기본값으로 시작`
- S05 악기 자유연주: 악기별 연주 영역, 장단, 레이어, 완료

S05에서 `완료`를 누르면 독립 완료 화면 없이 작업이 자동 저장되고 S07로 이동한다.

### 트랙/레이어 편집

- S07 트랙/레이어 편집: 현재 작업, 박자 그리드, 트랙 목록, 트랙 추가, 내보내기
- S08 트랙 추가: 악기 연주 추가, 장단/반주 추가, 가져오기 잠금
- S09 추가 악기 녹음: 기존 작업 위에 새 악기 테이크 적용
- S10A 라이브 장단 가이드: 연주 중 장단 가이드 적용, 트랙 생성 없음
- S10B 반주 트랙 만들기: 장단/반주 트랙 생성 후 S07 복귀

S10A와 S10B는 같은 장단 프리셋을 쓰지만 책임은 분리했다. S10A는 연주 보조, S10B는 편집 가능한 반주 트랙 생성이다.

### 따라하기

- S13 민요 선택: 아리랑, 도라지, 뱃노래
- S14 따라하기 악기 선택: 가야금, 장구, 대금과 추천 배지
- S15 따라하기 연주: 가이드 하이라이트와 완주 CTA
- S16 결과 / AI 피드백: 점수, 로컬 템플릿 피드백, 저장, 공유

따라하기 결과는 자유창작 작업으로 자동 변환하지 않는다. 저장 또는 공유 시 `PracticeResult`로 보관함의 결과 목록에 들어간다.

### 공유, 보관함, 설정

- S17 공유 준비: 내보낸 음원 또는 따라하기 결과를 공유 대상으로 확인
- S18 보관함: `작업`과 `내보낸 음원 / 결과` 분리
- S19 연주 상세 / 플레이어: 내보낸 음원 또는 결과 재생과 공유
- S20 쉐어 / 둘러보기: 데모 피드
- S21 공유 곡 상세: 리믹스와 저장 흐름
- S22 마이 / 설정: 게스트 상태, 로컬 보관함, 로그인 CTA
- S23 로그인 / 보관함 동기화: 로그인, 동기화, 건너뛰기

로그인은 앱 시작 조건이 아니다. S22/S23에서 `아이디에 저장된 내가 만든 곡 불러오기` 맥락으로만 진입한다.

## 제외 화면

- S06 연주 완료 확인: S05 완료 후 S07로 바로 이동
- S11 반주 적용 후 편집: S10B 적용 후 S07로 바로 이동
- S12 따라하기 모드 상태: S01 홈의 토글 상태로 흡수

세 화면은 전이 머신에서 독립 navigation 대상이 되지 않도록 막았다.

## 데이터 구조

이번 구현에서 추가된 핵심 모델은 다음과 같다.

| 모델 | 역할 |
| --- | --- |
| `Work` | 편집 가능한 작업 단위 |
| `Track` | 작업 안에 쌓이는 악기, 반주, 참조 레이어 |
| `Take` | 녹음 시도와 이벤트 목록 |
| `ExportedAudio` | 공유 가능한 내보낸 음원 |
| `PracticeResult` | 따라하기 결과와 피드백 |

자동 저장된 `Work`는 공유 가능한 산출물이 아니다. 공유 대상은 `ExportedAudio` 또는 `PracticeResult`다.

## 검증 결과

자동 검증:

```bash
npm test
npm run typecheck
```

결과:

- Vitest: 48개 테스트 파일, 399개 테스트 통과
- TypeScript: `tsc --noEmit` 통과

웹 렌더 검증:

- Expo 웹 서버: `http://localhost:8086`
- 홈 화면 렌더 확인
- 자유창작 -> 장구 선택 -> 기본값 시작 -> 완료 -> S07 트랙/레이어 편집 진입 확인
- 모바일 폭 홈 렌더 확인
- Playwright page error와 console error 없음

## 남은 범위

이번 구현에서 의도적으로 제외한 항목은 다음과 같다.

- 실기기 오디오 지연 검증
- 실제 샘플 다운로드와 캐시
- 실제 오디오 인코딩과 OS 공유 시트
- 실제 로그인 제공자와 계정 동기화
- 실제 커뮤니티 피드 백엔드
- 악기별 정교한 연주 엔진 확장

다음 구현 단계는 이 화면 셸 위에 악기별 입력면, 샘플 준비 상태, 실제 저장소, 오디오 내보내기, 공유/로그인 연동을 순차적으로 붙이는 것이다.
