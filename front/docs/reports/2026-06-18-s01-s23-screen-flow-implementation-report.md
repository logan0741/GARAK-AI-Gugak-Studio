## 요약

S01-S23 화면 구성 논의 결과를 Expo 앱의 실제 화면 흐름 셸로 구현했다. 이번 구현은 실기기 오디오 검증, 실제 로그인, 실제 공유 API, 실제 음원 인코딩을 제외하고, 사용자가 각 화면을 이동하며 제품 구조를 확인할 수 있는 수준을 목표로 했다.

앱 진입점은 기존 가야금 기술 프로토타입에서 `GARAK` 화면 흐름 앱으로 교체했다. 기존 프로토타입 코드는 삭제하지 않고 `src/prototype/`에 보존했다.

팀 리뷰용 시각 자료는 `2026-06-18-s01-s23-screen-flow-visual-map.md`에 분리했다.

## 2026-06-23 Figma 디자인 이식 추가

Figma `2026 솔챌`의 `디자인 시스템` 프레임(`180:999`)과 `디자인` 섹션(`288:294`)을 직접 확인하고, 화면 셸을 피그마 기준에 더 가깝게 교체했다.

반영한 핵심 요소:

- 디자인 시스템 색상 `#1A1C2D`, `#B51A14`, `#E59100`, `#F9F7F3`를 `garakDesignSystem` 토큰으로 고정
- GARAK wordmark, pill button, segmented mode control, quick access pill, mini player, progress bar, 악기 chip/preview 공통화
- 홈, 자유창작, 보관함, 쉐어, 설정/로그인 화면을 Figma의 rounded card, dark surface, amber accent 중심으로 재구성
- `마이 / 홈 / 쉐어` quick access가 실제 상태 머신 전이와 맞도록 S18/S20/S22 이동 정의 보강
- Figma에서 장구가 선택된 것처럼 보이는 기본 악기 상태를 실제 `startWithDefaults` 흐름에 연결

의도적으로 연결하지 않은 항목:

- 사용자가 제외를 명시한 `플레잉` iPhone mockup 배경
- 로그인 첫 실행 강제 진입
- 생성형 오디오로 오해될 수 있는 `AI 반주 생성`; 현재는 로컬 장단 추천/프리셋 시퀀싱으로 제한
- 실제 오디오 믹싱, 파일 내보내기, 원격 공유 피드 업로드
- 잠금 악기 슬롯의 결제/권한 기능

시각 QA에서 발견해 수정한 항목:

- 악기 선택 화면의 기본 장구 표시와 비활성 `Next` 상태 불일치
- JSX 속성 문자열의 `\n`이 화면에 그대로 노출되던 헤딩
- 보관함에서 쉐어로 이동할 때 상태 머신이 `S18 -> S20` 전이를 막던 런타임 오류

## 구현된 화면 구조

### 홈과 자유창작

- S01 홈: `자유창작 모드 / 따라하기 모드` 토글, 큰 설명 카드, `Next`, 홈 전용 `마이 / 홈 / 쉐어`, 입문 가이드 진입
- S03 입문 가이드: 기본 제스처 안내 후 S05 진입 가능
- S04 악기 선택: 가야금, 장구, 대금 선택과 추후 악기 잠금 슬롯
- S04A 연주 기본 설정: 악기별 설정 항목과 `기본값으로 시작`
- S05 악기 자유연주: 악기별 연주 영역, 장단, 레이어, 완료

S05에서 `완료`를 누르면 독립 완료 화면 없이 작업이 자동 저장되고 S07로 이동한다.

### 트랙/레이어 편집

- S07 트랙/레이어 편집: 현재 작업, 박자 그리드, 트랙 목록, 트랙 추가, 내보내기
- S08 트랙 추가: 악기 연주 추가, 장단/반주 추가, 가져오기 잠금
- S09 추가 악기 녹음: 기존 작업 위에 새 악기 테이크 적용
- S10A 라이브 장단 가이드: 연주 중 장단 가이드 적용, 트랙 생성 없음
- S10B 반주 트랙 만들기: 장단/반주 트랙 생성 후 S07 복귀

S10A와 S10B는 같은 장단 프리셋을 쓰지만 책임은 분리했다. S10A는 연주 보조, S10B는 편집 가능한 반주 트랙 생성이다.

### 따라하기

- S13 민요 선택: 아리랑, 도라지, 뱃노래
- S14 따라하기 악기 선택: 가야금, 장구, 대금과 추천 배지
- S15 따라하기 연주: 가이드 하이라이트와 완주 CTA
- S16 결과 / AI 피드백: 점수, 로컬 템플릿 피드백, 저장, 공유

따라하기 결과는 자유창작 작업으로 자동 변환하지 않는다. 저장 또는 공유 시 `PracticeResult`로 보관함의 결과 목록에 들어간다.

### 공유, 보관함, 설정

- S17 공유 준비: 내보낸 음원 또는 따라하기 결과를 공유 대상으로 확인
- S18 보관함: `작업`과 `내보낸 음원 / 결과` 분리
- S19 연주 상세 / 플레이어: 내보낸 음원 또는 결과 재생과 공유
- S20 쉐어 / 둘러보기: 데모 피드
- S21 공유 곡 상세: 리믹스와 저장 흐름
- S22 마이 / 설정: 게스트 상태, 로컬 보관함, 로그인 CTA
- S23 로그인 / 보관함 동기화: 로그인, 동기화, 건너뛰기

로그인은 앱 시작 조건이 아니다. S22/S23에서 `아이디에 저장된 내가 만든 곡 불러오기` 맥락으로만 진입한다.

## 데이터 구조

이번 구현에서 추가된 핵심 모델은 다음과 같다.

| 모델 | 역할 |
| --- | --- |
| `Work` | 편집 가능한 작업 단위 |
| `Track` | 작업 안에 쌓이는 악기, 반주, 참조 레이어 |
| `Take` | 녹음 시도와 이벤트 목록 |
| `ExportedAudio` | 공유 가능한 내보낸 음원 |
| `PracticeResult` | 따라하기 결과와 피드백 |

자동 저장된 `Work`는 공유 가능한 산출물이 아니다. 공유 대상은 `ExportedAudio` 또는 `PracticeResult`다.

## 2026-06-23 Figma 정밀 이식 2차

Figma `2026 솔챌`의 `디자인` 프레임(`288:294`)과 `디자인 시스템` 프레임(`180:999`)을 다시 확인하고, 393x852 기준 스크린샷을 현재 Expo Web 렌더링과 나란히 비교했다. 이번 라운드는 기능을 유지하면서 최대한 원본에 가깝게 복제하는 것을 우선했다.

### 재사용 구조

- 디자인 토큰은 `src/product/garakDesignSystem.ts`에 유지한다. 핵심 색상은 `#1A1C2D`, `#B51A14`, `#E59100`, `#F9F7F3` 기준이다.
- 공통 UI는 `src/product/garakUi.tsx`로 모았다. `GarakWordmark`, `ScreenHeading`, `PrimaryPillButton`, `QuickAccessNav`, `VisualHero`, `FigmaImagePanel`을 화면별로 재사용한다.
- 화면 이미지 자산은 `GARAK_SCREEN_ASSETS` 한 곳에서 역할별로 매핑한다. 이미지가 바뀌면 화면별 JSX를 크게 고치지 않고 `front/assets/product/*` 또는 매핑만 바꾸는 구조다.
- 큰 Figma 크롭은 pixel match를 빠르게 맞추기 위한 임시 기준선이다. 장기 유지보수 단계에서는 히어로 이미지, 썸네일, 플레이어, 카드 배경처럼 더 작은 자산과 데이터 기반 컴포넌트로 쪼개는 것이 맞다.

### 이식된 화면

- S01 홈: Figma 히어로 이미지, PLAY 터치 영역, iOS 상태바 근사치, 상단 GARAK/프로필/좌측 원형 버튼, 하단 퀵 액세스 위치와 아이콘형 네비게이션을 반영했다.
- S04 악기 선택: Figma 칩 순서에 맞춰 `장구 -> 가야금 -> 대금`으로 표시하고, 기본 장구 선택 상태는 Figma 패널 자산을 사용한다. 다른 악기를 선택하면 기존 기능형 프리뷰로 전환된다.
- S18 라이브러리: Figma의 어두운 플레이리스트 패널을 이식하고, 패널 위 투명 터치 영역으로 작업 열기와 홈/쉐어 이동을 연결했다.
- S20 쉐어: 카테고리 칩, 추천 히어로, 내 GARAK 플레이어, 최근 재생 스트립을 Figma 자산으로 교체하고 상세/공유 준비/최근 항목 이동을 투명 터치 영역에 연결했다.

### 의도적으로 남은 차이

- GARAK 로고는 Figma 스크린샷 크롭 자산으로 맞췄다. 아직 벡터 원본은 아니므로 Figma 로고 원본 벡터를 export하면 `GARAK_SCREEN_ASSETS.brand.wordmark` 자산만 교체하면 된다.
- iOS 상태바 아이콘은 구조형 View로 근사했다. 실제 시스템 아이콘과 픽셀 단위로 같지는 않다.
- S18/S20의 리스트 콘텐츠는 현재 Figma 데모 이미지를 그대로 보여준다. 터치 동작은 연결되어 있지만, 이미지 안의 제목/날짜/썸네일은 앱 상태 데이터로 렌더링되는 구조가 아니다.
- S01에서 Figma 원본에 없는 `자유창작 / 따라하기` 모드 토글은 제거했다. 따라서 따라하기 모드의 직접 진입 UI는 현재 홈에서 보이지 않는다. Figma에 별도 진입점이 추가되거나 설정/입문 화면에 연결 지점이 필요하다.
- `플레잉` 배경에 비치는 iPhone mockup은 사용자 요청대로 이식하지 않았다.
